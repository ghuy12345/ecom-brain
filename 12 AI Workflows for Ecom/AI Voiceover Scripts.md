# AI Voiceover Scripts

## What it is
An AI voiceover laid over product B-roll you already own lets you make video ads without waiting on creators: no reshoots, no mispronunciations, fast turnaround. Two skills make it work. First, writing a script with real pull for problem-aware and unaware viewers. Second, formatting that script inside the voice tool so the read sounds like a person. Pasting a brief in unedited almost always sounds robotic.

## When to use it
- When you have usable B-roll but no creator footage for a new angle.
- When you want to test top-of-market angles (problem-aware and unaware), where most operators are weakest.
- When you want to test the same script across different avatars quickly.

## How (steps)
**Writing the script**
1. Load the research document, avatar, product information and reviews into your brand project. Trim review files to a few hundred of the best rows; if usage limits bite, tell the model to ask for the review file only at the step that needs it.
2. Ask for hooks first. Each should come with the mass desire it targets, how you would test it, how it should look, what the test should teach you and the principle behind it.
3. Pick your top three hooks, then request holds. Ask for a short cut of 30 to 45 seconds or a longer cut of 60 to 90 seconds; older audiences often tolerate longer.
4. Push back. When a script reads flat, say it has no suspense and does not feel like something the viewer stumbled on, then request a rewrite that ends in a natural call to action toward the link.
5. If the model picks an avatar that does not fit, reject it and request a different one.
6. Remember that virality without a buying path does nothing; every script needs sales intent. You remain responsible for every claim.

**Formatting the voiceover**
1. Choose a voice in the tool's library (filter by language, accent, age and use case), preview it and save it. Use the most natural-sounding model available; standard quality is usually enough.
2. Break the script into separate chapters, one per section, each labelled (first hook, second hook, hold, CTA).
3. Generate, listen, reformat, regenerate. Some lines need several attempts.
4. Apply formatting techniques:
   - merge lines spoken in one breath to avoid odd pauses
   - capitalise words to emphasise
   - remove unneeded commas; use an exclamation mark for energy
   - replace ellipses in lists with commas or dashes
   - insert explicit breaks (tools usually cap a pause at a few seconds) rather than writing "pause"
   - start sentences with small connectives such as "And" or "So"
   - strip out any editor notes that slipped into the spoken text
5. Treat voice settings as starting points. Moderate stability and similarity with a little style exaggeration is a reasonable start; raise style if emphasis sounds flat. Tune per voice.
6. Alternatively, record the read yourself, then run it through a voice-changer so you keep your pacing and tone with a different voice.

## Example
Say a hypothetical air-purifier brand has a library of product B-roll. The script opens on a personal health story about learning, after an illness, how much the air at home matters, then contrasts cheap models with a better-filtered one, and closes with a CTA. One line needs half a dozen regenerations before the stress lands on the right word. The goal is organic, not perfect; a small imperfection makes it sound more real. This kind of ad (AI voice, existing B-roll, a modest personal story) can perform as well as a creator video.

## Common mistakes
- Blaming the tool for a robotic read when the script was never formatted.
- Repeating the same phrase in nearby lines.
- Cloning someone's voice without permission.
- Declaring a script a winner before it has been tested.
