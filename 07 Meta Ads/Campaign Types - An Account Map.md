# Campaign Types - An Account Map

## What it is
A mature Meta account usually holds a small number of campaigns, each with one clear job. Knowing the full map helps you resist adding structure you do not need yet. The core idea: one main campaign does almost all the work, and every other campaign exists only because it answers a question the main one cannot.

## When to use it
- When you are deciding whether to add a second campaign.
- When inheriting an account full of campaigns nobody can explain.
- When daily spend crosses a new level and you wonder what changes.

## How (steps)
1. **Main acquisition campaign (budget at campaign level).** Broad targeting. Each ad set is one creative concept, tested as three creatives with two primary texts and two headlines. This is where new ads and new landing pages are tested, because ads that cannot win spend here cannot scale anyway.
2. **Landing-page test ad set (once spend is meaningful).** Only after an angle is proven and spend is no longer very small: duplicate your top three to five ads, change only the URL to the new page, and launch them as their own ad set inside the main campaign when cost efficiency matters most, or as a separate ad-set-budget test when you have more budget and want a cleaner read. See [[Testing Landing Pages Through Ad Spend]].
3. **Winner-isolation campaign (budget at ad-set level).** Proven winners get their own ad set with a fixed budget, so new ads cannot starve them. Attribution and exclusion tests can run here as extra ad sets. See [[Isolating Winners in a Dedicated ABO]].
4. **Cost-capped recycling campaign (conditional, lowest priority).** Only under the conditions in the section below. If you run one: a single ad set with a cost-per-result goal set about 20% below target CPA, starting at roughly 10% of daily spend, holding ads that make money without being top performers. If something has two good days, scale it like any other campaign.
5. **Creator-vs-creator test campaign (optional).** Only when you specifically want to compare creators against each other; otherwise creator content tests alongside everything else in the main campaign. See [[Raw Creator Content Campaigns]].
6. **Sale campaign.** Real limited-time promotions only, built as described in [[Sale-Period Campaign Structure]].

**Which levels you need, by daily spend (bands overlap):**
- Up to about $3k/day: one main campaign. Strong creative alone can carry this structure much further.
- About $3-10k/day: add a creator-vs-creator test campaign if you want that comparison.
- About $10-50k/day: add winner isolation, an automated shopping campaign for profitable ads, and whitelisted creator ads.
- $50k+/day: segment by country, product line or avatar.

Ad-set budgets have a limited role below about $2k/day: they can squeeze perhaps 20-30% more spend from existing ads but rarely find new breakthroughs.

## Ads the main campaign passes over
**Never force spend onto ads the system ignored.** When the main campaign gives an ad little or no spend, that is the verdict. As a rough estimate, around 99% of ads that fail to win spend would not have beaten the winner anyway, so pushing budget onto them to "give them a fair test" wastes money nearly every time. Forced spend also tends to harvest people already set on buying, which flatters the numbers.

**Do not switch them off either.** Leave unspent ads running where they are. They cost nothing while they get no delivery, and the system can still pick one up later if conditions change. Keep treating the ads that win spend as your better ads, and let the rest go in the sense of not chasing them.

**Recycling into a cost cap is a conditional option, not a default.** Consider it only when all of these hold: you produce many ads, you have spend to spare beyond the main campaign, you can measure whether its sales are incremental, and you treat it as low-maintenance harvesting rather than proof that weak ads were secretly good. Desires shift with seasons, so an ad that failed one month can occasionally sell in another. If you run it, keep it capped, low priority, judged on its own numbers, with an exit rule for every ad, and never mistake it for a scaling lever. Watch for high frequency with weak return, a sign it is re-serving existing audiences.

## Example
Say a home-goods brand spends $1,500 a day across seven campaigns built by a previous agency. Mapping them, five have no defensible job. The brand consolidates into one main campaign with a champions ad set and four concept tests, adds a landing-page test ad set when a new advertorial is ready, and leaves concepts that win no spend running untouched rather than forcing budget onto them. Months later, launching a dozen concepts a week with spend to spare, it adds a small cost-capped recycling campaign and judges it on incremental sales.

## Common mistakes
- Copying the structure of an account spending fifty times more than you.
- Running a two-landing-page creative test (six ads per ad set) below about $2k/day, which spreads spend too thin.
- Running "sale ends tonight" promo campaigns that never end.
- Forcing budget onto ads the main campaign ignored, or switching them off in frustration instead of leaving them running.
